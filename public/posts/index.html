Port Already in Use

If when restarting your django server locally you get the message: `Error: That port is already in use.` All you have to do is kill all the processes associated with the port in question. To do that simply type on your terminal: sudo fuser -k 8000/tcp # this command will kill all processes associated with port 8000 You can also use the command line network utility tool netstat to kill the process associated with the port Django is running on. ...
