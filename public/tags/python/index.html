Docker Cheat Sheet

Dockerfiles: plain text instructions to automatically make images. Docker containers: the active, running parts of Docker that do something. Docker images: pre-built environments and instructions that tell a container what to do. Check if a docker container is running docker inspect -f {{.State.Running}} container_id To list all Docker containers you can use one of the following commands: docker ps -as docker ps -aq docker ps -a List all Docker images: docker images ps docker images -a Remove a specific docker container docker rm <container_id> Force remove all Docker containers docker rm -f $(docker ps -a -q) Remove a specific Docker image docker rmi <image_id> Force remove all Docker images docker rmi -f $(docker images -q) Running docker with auto remove containers docker run --rm <image_name> <CMD> # Execute shell in Docker container docker exec -it <container_id> /bin/bash # Execute shell in container using Docker Compose docker-compose exec <service_name> /bin/bash # Dockerfile example FROM r-base:latest # for python 2.7 (FROM python:2.7) # Set a default user.
